# Proyecto de Red en Cisco Packet Tracer

## Descripción
Breve explicación de la topología (por ejemplo: Red LAN empresarial con VLANs, enrutamiento inter-VLAN y servidor DHCP/Wireless).

## Topología
![Diagrama de la Red](capturas/diagrama_red.png)

## Dispositivos y Configuración
- **Router:** Configuración de Subinterfaces, NAT y ACLs.
- **Switch:** Creación de VLANs (VLAN 10, VLAN 20) y puertos Troncales.
- **Wireless Router:** Configuración de WPA2-Personal y rango DHCP.

## Pruebas de Conectividad
- Pruebas de `ping` exitosas entre PCs de distintas VLANs.
- Acceso al servidor web (`skillsforall.srv` o IP pública).

## Requisitos para Abrir el Archivo
- Cisco Packet Tracer versión 8.x o superior.
